# Simple Calculator 🧮

This is a simple, clean and responsive Calculator web application built using **HTML**, **CSS**, and **JavaScript**.

The calculator supports basic arithmetic operations like addition, subtraction, multiplication, and division.  
It is designed inside a neat **square box layout** for better aesthetics and user experience.

---

## ✨ Features

- Basic arithmetic operations (+, -, *, /)
- Clear (`C`) button to reset input
- Responsive design
- Stylish green and red buttons
- Error handling for invalid inputs

---

## 📂 Project Structure
Calculator/ 
          ├── index.html 
          ├── style.css 
          └── script.js

- `index.html` → Markup for the calculator layout.
- `style.css` → Styling for calculator (green/red buttons, box layout, responsiveness).
- `script.js` → Logic for calculator operations.
